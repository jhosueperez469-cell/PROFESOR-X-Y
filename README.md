# Certificado Web listo para GitHub Pages

Estructura requerida:
```
/
├─ index.html
└─ index_archivos/
      image001.png
      image002.png
```

Cómo publicarlo:
1. Sube `index.html` y la carpeta `index_archivos/` al repositorio.
2. En **Settings → Pages**, elige:
   - Branch: `main`
   - Folder: `/ (root)`
3. Guardar.

La página quedará visible en:
https://<usuario>.github.io/<repositorio>/

El archivo actualiza automáticamente la fecha cada día.
